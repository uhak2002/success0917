# 프로젝트 궁극 목적 (자동화 방향성 참고 자료)

> 지금 만들고 있는 자동화 도구들(영상 편집 등)이 최종적으로 어디에 쓰이는지에 대한 배경 문서.
> 세부 실행 계획은 아니며, 앞으로 기능을 설계할 때 참고할 상위 목표.

## 1. 고객 DB 확보를 위한 유학 고민 해결 정보 컨텐츠 발행

- 유학 관련 고민을 해결해주는 정보성 콘텐츠를 발행해서 잠재 고객 DB를 확보하는 것이 목적.
- 콘텐츠 발행 자동화(글쓰기, 카드뉴스, 영상 등)가 이 목표와 연결됨.

## 2. SNS 영상/이미지 자동화

- **인스타 쇼핑 쇼츠** 영상 자동화
- **릴스**용 영상 자동화
- **카드뉴스** 등 이미지 자동화

→ 지금 만들고 있는 `samples/video_editing/edit_video.py` (무음 컷 + 자막 + MZ 말투 + 예능 효과)가 이 목표의 첫 단계에 해당함. 이미지(카드뉴스) 자동화는 `samples/generate_icons.py`(OpenAI 이미지 생성)와 연결 가능.

## 3. 스레드 쇼핑을 위한 제품 발굴 + 글 발행

- 스레드(Threads) 쇼핑에 올릴 제품을 발굴하고, 그에 대한 글을 자동으로 발행하는 것.
- 아직 구체적인 구현은 없음 — 제품 리서치(트렌드/키워드 분석 등) + 글 생성 자동화가 필요할 것으로 예상.
