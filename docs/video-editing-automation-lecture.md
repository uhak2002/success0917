# 영상 편집 자동화 — 강의 요약 (참고 자료)

> 출처: "11. 집 밖에서도 가능한 '영상 편집 자동으로 해줘'" 강의 요약
> 목적: 향후 영상 편집 자동화 워크플로우 구현 시 참고용 원본 노트. 아직 구현 계획은 아님.

## 핵심 아이디어

- 영상 편집 워크플로우를 프로그램화하고 API 키를 연결한다.
- **로컬 PC 작업**: 시간·비용 면에서 효율적 (특히 GPU가 좋은 PC).
- **깃허브로 코드 동기화**: 로컬에서 작성한 코드를 깃허브에 올리면, 클라우드 환경과 합쳐져서 어디서든(폰 포함) 자유롭게 작업 지시 가능.
- 본인/타인 영상에 원하는 말투, 자막 글자체, 디자인 등을 적용해 편집을 자동화하는 프로그램을 목표로 함.
- 구글 드라이브 `inbox`에 원본 영상 업로드 → 클로드 코드/코덱스가 클라우드에서 편집 → 편집본을 `outbox`로 업로드.

## GPU vs CPU

- **GPU 필요 작업**: 인코딩(압축/저장) 속도 향상, 얼굴 인식·모자이크, 업스케일링 등 픽셀 단위 대량 반복 연산.
- **CPU만으로 가능한 작업**: 일반적인 영상 편집 — 무음 구간 탐지 후 컷 편집, 자막 삽입 등.

## 영상 편집을 시키는 방법

1. **로컬 실행**: 구글 드라이브에서 영상을 다운로드 → 클로드 코드/코덱스에게 편집 지시 → 결과물을 구글 드라이브에 업로드.
2. **클라우드 VM 실행**: 클라우드 가상머신에서 동일 작업 수행.

### 클로드 코드로 자동화

- 클로드 코드 UI에서 [로컬] / [클라우드] 환경 선택 가능.
- 클라우드 환경 네트워크 액세스: 사용자 정의 도메인 추가 가능 (예: `*.naver.com`, `*.youtube.com`).
- 레포지토리를 연결해두면 PC를 꺼도 핸드폰으로 이어서 작업 지시 가능.
- 세션 이동: 대화창 → 우측 `...` → "다음에서 열기" → 클라우드 → 세션 이어가기.
- 자동화 예시: 구글 드라이브 `inbox`에 원본 업로드 → 편집 후 `outbox` 업로드 → 인스타 릴스/유튜브 등에 자동 업로드까지 연결.
- GPU가 좋은 로컬 PC: 속도·품질 우수 → 무거운 작업은 로컬에서.
- 클라우드: 간단하거나 용량이 작은 작업 위주로.

### 코덱스로 자동화

- 로컬 PC 프로젝트: 소스 폴더로 `success0917` 선택.
- 클라우드 프로젝트: 별도 프로젝트(`cloud_test` 등) 생성.

### 클라우드 VM 사양 참고

- GPU 없음 / CPU 4코어 / RAM 15Gi(16GB) — 코딩·경량 작업 위주.
- CPU: 처리 속도, RAM: 동시 작업 처리량, Boot/Block Volume: 스토리지 용량.

### 로컬 PC 사양 예시

- 예1: Intel i5-8265U(1.60GHz), RAM 16GB (실사용 약 15.86GB) — 경량 작업용.
- 예2: 24 vCPU 상당(i7-13700F, 16코어/24스레드), RAM 32GB, GPU RTX 4070 Ti 12GB — 무거운 영상 편집·인코딩에 적합.

## 앞으로의 방향 (강의 결론)

1. 영상 편집 워크플로우를 만들고 프로그램화한다.
2. API 키를 연결한다.
3. 로컬 PC에서 무거운 작업(인코딩, 업스케일링 등)을 처리해 시간·비용을 절약한다.
4. 코드는 깃허브에 올려 클라우드와 동기화, 어디서든 이어서 작업할 수 있게 한다.
